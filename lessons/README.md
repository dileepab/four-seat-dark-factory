# Lessons

These are the seats' own notes. Claude Code's auto-memory lets a seat write a note when it learns something that should outlast the session. All four seats in this repository share one memory directory, and each note is copied here unchanged. [`INDEX.md`](INDEX.md) is the index a seat loads at the start of a session.

**The submitted run started with no notes.** The memory directory for this repository was new, so the seats began with nothing but `PROTOCOL.md` and their mandates. Every note here was written by a seat during the submitted run. Each note's `originSessionId` says which session wrote it.

The lessons from the earlier runs reached this one in a different form. They were rewritten as generic rules in `PROTOCOL.md` and the mandates before the run, so that nothing in a seat's standing instructions names the product (see "How it got here" in [FACTORY.md](../FACTORY.md)).

No human wrote or edited a note.

To start another band with what these seats learned, copy these files into that band's Claude Code project memory directory, `~/.claude/projects/<project path with / as ->/memory/`, and rename `INDEX.md` to `MEMORY.md`. To give it the start this run had, leave that directory empty.
