# Working agreement for coding agents in this repository

This repository is built by a band of coding agents that coordinate in a BAND room.

- Your role is the role you were given when you went online in BAND: planner, builder, verifier, or critic.
- Before doing any work, read `PROTOCOL.md` and your mandate: the file in `mandates/` whose name starts with your role (for example `mandates/planner.md` or `mandates/planner-<suffix>.md`). They are your standing instructions for the whole session. Where a generic role skill disagrees with them, follow the mandate.
- If you were not given one of these roles, say so in the room and stop.
- The task arrives in the room. The standing instructions never change from task to task. Only the task does.
- Use the absolute paths the task gives. Commit only in the repository the task names.
